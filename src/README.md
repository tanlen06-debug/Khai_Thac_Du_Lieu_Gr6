# src/

Dành cho các hàm Python dùng chung sau khi các thành viên thống nhất giao diện, ví dụ:
- Tải và kiểm tra dữ liệu
- Cấu hình `random_state` và các phép đánh giá
- Lưu bảng/biểu đồ vào `outputs/`

Chưa triển khai mã trong giai đoạn khởi tạo để tránh gán trước kết quả hoặc thay đổi cách làm của thành viên.
